# CA031: a control allocation parameter does not exist in this PX4 version

Level: warning

## What it checks

The input sets a parameter whose name starts with `CA_` and that the PX4
version of the engine does not have.

Parameters of other modules that do not exist are listed under "Notes" only: a
full parameter export usually contains some, and they do not change the
allocation.

## Why it matters

The parameter is ignored. If the name is misspelled, for example
`CA_ROTOR4_PZZ`, the parameter that was meant keeps its default value and the
report is for another configuration. If the file is for another PX4 version
than the engine, the result does not describe that version.

## What to do

Check the spelling. If the name is right, check which PX4 version the file is
for and use an engine built against it; the report names the PX4 version of the
engine in its header.
